## 1. Purpose

Define the framework that **generates governance systems from principles** rather than hand-authoring or
manually privileging them. Its input is `Principles + Meta-Constitution`; its output is **Governance Models**
that are principle-compliant by construction and provably traceable to their authority.

```
Input:  Layer-0 Invariant Principles (PCAMG-0002)  +  Meta-Constitution (PCAMG-0003)
Output: Governance Models (constitutions, policies, domain governance, decision-rights)
```

No governance structure may be manually privileged: every governance model is either generated by this
framework or authored under an equivalent governed act and then validated identically.

## 2. Required Capabilities

The framework MUST provide six capabilities over governance architectures:

| Capability | Definition | Principle anchors |
|------------|------------|-------------------|
| **Generate** | Produce a candidate governance model from selected principles + Meta-Constitution articles, with full derivation traceability. | IP-01, IP-02, PRIN-014 |
| **Validate** | Prove the candidate is principle-compliant, internally consistent, non-contradictory with higher layers, and scope-complete (via `PCAMG-0007`). | Art. M-VI, PRIN-006 |
| **Compare** | Diff two governance models across principle-coverage, decision-rights, and risk; surface conflicts. | PRIN-004 |
| **Simulate** | Execute the model against scenarios in a sandbox to observe decisions/outcomes without any real effect. | PRIN-014, PRIN-015 |
| **Evolve** | Produce a migration from one governance model to a successor (migration-only, backward-compatible, reversible). | IP-14, IP-15, PRIN-014 |
| **Retire** | Supersede a governance model with links, migrate dependents, and record retirement. | Art. M-V, INV-10 |

## 3. Generation Contract (determinism & traceability)

- **Deterministic (IP-01/INV-6).** Given the same principles, Meta-Constitution version, and generation
  inputs, generation produces the same governance model (reproducibility-by-record; result hash).
- **Traceable (IP-08).** Every generated element declares the principle(s) and article(s) it derives from; a
  generated model with any underived element is rejected.
- **No hardcoding (IP-01/IP-02).** Governance content is composed from registry-resolved principle records and
  Meta-Constitution articles; no governance literal is embedded in the generator.
- **Separation of duties (PRIN-009).** The generator proposes; a distinct validator certifies; the Authority
  Board (or delegated council) ratifies. The generator holds no commit power.
- **Fail-closed (Art. M-X).** Any generation lacking a complete derivation or failing validation yields **no**
  governance model (deny), not a partial one.

## 4. Generation Pipeline

```
Select Principles + Meta-Constitution articles
   → Generate candidate governance model (with derivation map)
   → Validate (PCAMG-0007 compliance proof; consistency; coverage; SoD)
   → Simulate (sandboxed scenarios; no real effect)
   → Compare (vs incumbent, if any)
   → Certify (distinct authority)
   → Enroll (Authority Board, AUTH-012)  ← the only act that confers authority
   → Operate → Measure (PCAMG-0006)
```

Every stage is audited (PRIN-006); enrollment is the sole authority-conferring act and is reserved to the
Board / delegated councils (`PCAMG-0005`).

## 5. Generated Governance Model — required structure

A generated governance model MUST declare: identifier; purpose; scope; principle derivation; owning domain;
decision-rights matrix; escalation path (terminal at Authority Board); separation-of-duties assignment;
validation record; audit obligations; evolution/retirement rules. A model missing any is invalid.

## 6. Anti-Privilege Rule

No governance structure — including the Meta-Constitution's own administration and the Authority Board's
procedures — may be exempt from generation-grade validation. The Authority Board's *authority* is
principle-derived (PRIN-001); its *procedures* are governance models subject to this framework.

## 7. Relationship to Existing UCOS Generators

UCOS already contains governed generators (Prompts 01–12, the program compiler, the fabric design pattern).
This framework **generalizes** that pattern to governance models specifically and binds it to Layer-0
principles. It does not replace the existing prompts; it provides the meta-layer they would register under
if PCAMG is enrolled.
