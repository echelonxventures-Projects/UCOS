# specifications/

Reserved for **formal specifications**: requirements, capability specs, domain specs, API/OpenAPI/GraphQL contracts, data contracts, and acceptance criteria.

> EMPTY BY DESIGN. Populated only by later UCOS generator prompts.

## Expected future contents
- `requirements/` — functional & non-functional requirements
- `capabilities/` — capability specifications (traced to the Capability Catalog)
- `domains/` — domain specifications
- `contracts/` — API, event, and data contracts (OpenAPI/AsyncAPI/GraphQL/JSON Schema)
- `acceptance/` — acceptance criteria & verification specs

Traceability: every specification MUST link upward to a capability/domain and register in the Artifact Registry.
