# quality/

Reserved for **quality engineering assets** (test strategies, test suites configuration, quality metrics, coverage policies, validation harnesses).

> EMPTY BY DESIGN. No tests are generated during bootstrap.
> Quality policy is governed by `.claude/governance/quality-gates.md` and `.claude/skills/testing-architecture.md`.

Each quality artifact added later MUST:
- trace to acceptance criteria in `specifications/acceptance/`,
- support the validation factory (Prompt 11),
- feed certification (Prompt 12).
