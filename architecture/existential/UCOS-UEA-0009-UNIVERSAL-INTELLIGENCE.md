## 1. Overview
Defines governed cognition/decision systems over an abstract **Intelligence** attribute (O-12), so that human,
artificial, machine, collective, distributed, hybrid, emergent, and **unknown-future** intelligence participate
as governed Actors/Agents under the same authority model.

## 2. Intelligence Kinds (open set)
Human · Artificial · Machine · Collective · Distributed · Hybrid · Emergent · **Unknown future**. Each kind is
a metadata profile of an Actor; none is privileged in the architecture.

## 3. Intelligence Systems (conceptual capabilities)
Knowledge · Memory · Reasoning · Planning · Decision · Learning · Optimization · Simulation · Prediction ·
Agent · Autonomous Governance. Each is a Capability (O-05) realized by Engines (L4) behind contracts, with no
assumption about the underlying cognition substrate (proposed INV-18).

## 4. Governance Model (autonomy)
- All autonomous action is bound by **Approval-By-Exception** and the five-zone autonomous-agent governance
  (AUTH-009) — unchanged and applied uniformly to non-human intelligence.
- Every Agent maps to a **single accountable owner** (single-owner principle); autonomy never removes
  accountability.
- Decisions are auditable and traceable (INV-2 audit, AUTH-010); autonomous governance is delegated, bounded,
  and reconciled append-only (INV-10).

## 5. Security / Federation / Risk
- **Security.** Non-waivable S1/S3/S4 (INV-2); deny-by-default authorization for agent actions (INV-3).
- **Federation.** Collective/distributed intelligence federates by contract; no shared mutable cognitive state.
- **Risks.** Emergent-intelligence goal drift (bounded by zone governance + kill/quarantine authority);
  accountability gaps (bounded by single-owner mapping); over-delegation (bounded by Approval-By-Exception).

## 6. Open Questions
- Q1: Governance floor for admitting an *emergent* intelligence to Agent status.
- Q2: Attestation/interpretability expectations before autonomous-governance delegation.
